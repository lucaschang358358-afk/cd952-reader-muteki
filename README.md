# CD-952 現代化觸控全功能電子書閱讀器 v6

專為無敵 CD-952 (240 MHz ARM9 / Besta RTOS / Project Muteki) 打造的現代化電子書閱讀 App。

## v6 全新功能
1. **EPUB 真封面 ＋ 內嵌插圖顯示**：
   - 自動解析 EPUB OPF 真封面並建立 96×128 快速縮圖快取 (`<書名>.cov`)，書架直接顯示真實封面、開啟零卡頓。
   - 閱讀輕小說或圖文書時，自動識別 `<img>` / `<image>` 標籤，並於閱讀流中獨立全頁高清顯示內嵌 JPEG/PNG 插圖。
2. **頂部即時時鐘 ＋ 全年 365 天每日閱讀熱力圖 (`[3] 統計`)**：
   - 閱讀頁與書架頂部顯示即時系統時鐘 (`HH:MM`)，僅於分鐘變動時靜默刷新，零閃爍省電。
   - 新增左側 `[3] 統計` 專屬分頁：4 張 KPI 卡片（今日閱讀、連續打卡天數 Streak、今年累計、打卡天數）、**53 週 × 7 天 GitHub 風格全年 365 天閱讀熱力圖**（方向鍵或直接觸控點擊任意一天查看當日閱讀時長與翻頁數）、支援 `PgUp/PgDn` 切換年份，並顯示單書閱讀時長排行。
3. **完整保留 v5 全部功能**：
   - 真視覺化 PDF 引擎（支援 PDF 1.5+ ObjStm、2-byte 中文 CID、CMYK、JPEG/Flate 內嵌圖、5 段縮放與平移、單頁重排）。
   - 原生 PNG / BMP / TXT 支援、全畫面觸控點擊、彈窗防文字重疊、4 套現代主題、多組手動書籤 (`K`)、全文搜尋 (`F`)、章節目錄 (`C`) 與跳頁滑桿 (`G`)。
