# CD-952 現代化觸控全功能電子書閱讀器 v5 (PDF / EPUB / PNG / TXT / BMP)

專為無敵 CD-952 (240 MHz ARM9 / Besta RTOS / Project Muteki) 打造的現代化觸控閱讀 App。

## v5 四大重點修正與升級
1. **全面觸控點擊支援**：
   - 編譯時自動偵測 Muteki SDK 觸控介面 (`gen_touch_header.py`)。
   - 首頁可直接點擊左側導覽列、右上匯入按鈕、繼續閱讀大卡片、書封網格與 4 張主題色票；閱讀時點左 30% 上一頁、點右 30% 下一頁、點中間 40% 開啟選單，頂部與底部工具列全部支援點擊。
2. **徹底修正 PDF 空白頁問題**：
   - 新增 **PDF 1.5+ `/Type /ObjStm` 壓縮物件串流解包**（修正 Word / Chrome / Google Docs / Adobe 匯出的現代 PDF 變空白問題）。
   - 完整支援 `(...)` 內 2-byte 中文 CID CMap、分字型獨立 `/ToUnicode` 表、CMYK (`k`/`scn`) 色彩、巢狀 Form XObject 資源、1-bit 黑白掃描圖與 4 通道 CMYK JPEG，並對加密或不支援壓縮格式提供明確中文診斷卡。
3. **徹底根治彈窗選單與書本內容重疊**：
   - 顯示任何彈窗（閱讀控制面板、書籤、搜尋、跳頁滑桿）前，自動清除與裁切底層重疊文字並加上 75% 現代柔暗遮罩，視覺乾淨俐落。
4. **新增原生 PNG 解碼支援 (`png_tiny.c`)**：
   - 純 C 記憶體內解碼 `.png`（不寫任何暫存檔），支援單張 PNG 與編號 PNG 圖片書 (`001.png` ↔ `002.png`)。
