# CD-952 終極全能觸控電子書閱讀器 v8 (Ultimate Edition)

專為無敵 CD-952 (240 MHz ARM9 / 800×480 觸控＋實體鍵盤) 打造的旗艦級離線閱讀與養成工作站。

## v8 完整功能
- 24 款手繪精裝書封模板、閱讀狀態標籤、5 星評分、書架格式＋狀態雙篩選、立體資料夾與系列自動續讀
- 12 套現代主題、4 種字體渲染風格、4 檔字體大小、5 段行距、4 段邊距、4 種翻頁視覺過場動畫

- 統計中心 4 合 1：365 天熱力圖、近 7 天柱狀圖、12 個月趨勢圖、每日閱讀總結報告
- 閱讀 RPG Lv.1~99 等級稱號、60 個成就獎盃牆、每週 3 項隨機任務、每日閱讀目標與定期護眼休息提醒
